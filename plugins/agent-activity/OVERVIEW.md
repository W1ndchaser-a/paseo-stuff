Readable Agent Activity replaces Paseo's tool-call rows with expandable cards that show Input and Output as formatted, syntax-highlighted JSON, and gives Thinking rows a matching compact header. Long output is previewed at twenty lines, with Show all to expand it. Messages, approvals and the composer stay native.

Use the cards with the Full chat display. Through Paseo 0.16.0, they bypass tool-call grouping and keep tool-only turns from folding, so before switching to Collapse tool calls, Collapse turns or Summary, run "Activity: use native rows (Collapse or Summary)" from the Command Center on that client, and "Activity: use tool cards (Full display)" to switch back. The choice applies to that client only and resets to cards whenever the plugin reloads. Messages from other agents and heartbeats always keep the host's own rows.

The plugin runs entirely on the client and reformats data Paseo already received, without summarizing or rebuilding diffs. It has no network, filesystem, process or daemon-side behavior. Show all on a very large payload can be slow.

Do not enable it next to another plugin that replaces tool-call or Thinking timeline items. It requires Paseo 0.13.0 or later. Its automated checks pass with the Paseo 0.13.2 and 0.16.0 SDKs, including the 0.16.0 host presentation pipeline in all three chat display modes. The packed plugin and the published npm version also loaded on an isolated macOS 0.15.3 daemon. Its last live web-client check used Paseo 0.14.0. Upstream's transformed-work folding issue remains open. The Paseo desktop app and native iOS and Android are untested. It is a fork of Matt Cowger's Colorful Agent Activity.
